# Анализ магистерских программ российских вузов

Сбор и анализ данных о магистерских программах ведущих московских вузов:
сколько бюджетных и платных мест, какая стоимость обучения, по каким
направлениям подготовки.

## Что внутри

| Файл | Назначение |
|---|---|
| `Парсер_Поступи_ру.ipynb` | Парсер сайта «Поступи.онлайн»: постраничный обход каталога магистратуры, извлечение названия программы, числа бюджетных и платных мест, стоимости обучения и направления подготовки |
| `Обработка_данных_Ранхигс.ipynb` | Очистка, приведение к единому виду, анализ и визуализация собранных данных |
| `data/` | Выгрузки: РАНХиГС, Финансовый университет, МФТИ, РЭУ им. Плеханова, сводный файл по вузам |

## Задача

Программы магистратуры описаны на сайтах разрозненно, сравнивать их вручную
неудобно. Парсер приводит разрозненные карточки к табличному виду, после чего
вузы и направления можно сопоставлять по стоимости и доступности бюджетных
мест.

## Стек

`requests` · `BeautifulSoup4` · `pandas` · `matplotlib` · Jupyter
